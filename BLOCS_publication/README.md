# BLOCS – dossier de publication

Commencez par **GUIDE_PUBLICATION.md**.

- `blocs-perso.html` : votre version personnelle (menu caché, code 1140). Pas pour les stores.
- `www/index.html` : la version pour les stores (FR + EN).
- `capacitor/` : projet pour fabriquer les apps Android et iPhone.
- `store/` : captures d'écran, icônes, visuels, textes des fiches.
- `privacy/index.html` : politique de confidentialité à mettre en ligne.
- `source/` + `build.py` : code source et script de fabrication.
